# Thinktum Website Scroll

React/Vite/Three.js prototype for the Thinktum cinematic particle scroll experience.

## Included

- Scroll-driven particle scene in `src/components/thinktum`
- FBX source models in `public/models`
- Active design and plan docs in `docs/superpowers`
- Original build brief in `thinktum-scroll-experience-complete.md`

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
